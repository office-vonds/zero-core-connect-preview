# ZERO-CORE Connect｜画面共有

[画面共有ページを開く](https://office-vonds.github.io/zero-core-connect-preview/)

ZERO-CORE CMSから独立した、チャットの確認用画面です。掲載している顧客・スタッフ・会話はすべて架空データです。

## PCの画面

左側に顧客一覧、右側に会話、画面下部にメッセージ入力欄と送信ボタンを配置しています。上部には「お客様」「社内」「改修依頼」のタブと「改修を依頼」ボタンがあります。

![PC版の顧客チャット、入力欄と送信ボタン](https://raw.githubusercontent.com/office-vonds/zero-core-connect-preview/main/desktop.png)

[PC画像を直接開く](https://raw.githubusercontent.com/office-vonds/zero-core-connect-preview/main/desktop.png)

## スマートフォンの画面

会話を選ぶとトーク画面へ切り替わります。顧客への返信と社内メモは、色と保存先を分けて表示しています。

![スマートフォン版の会話と入力欄](https://raw.githubusercontent.com/office-vonds/zero-core-connect-preview/main/mobile.png)

[スマートフォン画像を直接開く](https://raw.githubusercontent.com/office-vonds/zero-core-connect-preview/main/mobile.png)

## 確認できる内容

- 顧客チャット：宛先の表示、未返信一覧、メッセージ入力・確認用保存。
- 社内トーク：顧客会話とは別のタブで、スタッフ同士の会話を表示。
- 社内メモ：顧客返信と切り替えて保存。顧客役割の画面には非表示。
- 改修依頼：幹部向けの専用フォームで件名と内容を確認用に保存。

実顧客への送信、実際のスマートフォン通知、予約確定、VONDSへの実送信、自動改修は接続していません。

[チャットを操作する](https://mhz-metro-biography-widescreen.trycloudflare.com/?v=20260910-display2)

操作用ページはブラウザごとの架空データを使用し、1時間で削除されます。この共有ページの画像・説明にはログインもJavaScriptも必要ありません。
